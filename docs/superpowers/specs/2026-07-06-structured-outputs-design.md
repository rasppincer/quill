# Spec: Transition to Pydantic Structured Outputs (Guaranteed JSON)

## Goal
Implement robust schema-guaranteed JSON outputs by integrating Pydantic models into the agent evaluation and feedback stage pipelines, eliminating fragile regex-based parsing and legacy machine decisions (`advance` / `loop_back`) in preparation for the manual-first stage transition.

## Architectural Changes

### 1. Pydantic Models for Structured Output
Define two primary output structures in [src/quill/agent.py](file:///home/bob/projects/quill/src/quill/agent.py):

*   **`ContentStageOutput`** (for content generation stages):
    ```python
    class ContentStageOutput(BaseModel):
        content: str = Field(description="The primary markdown text generated by the stage")
    ```
*   **`FeedbackStageOutput`** (for feedback/evaluation stages like `review` and `validate`):
    ```python
    class FeedbackStageOutput(BaseModel):
        critique: str = Field(description="Detailed feedback, annotations, and suggestions")
    ```

### 2. LLM Client Updates (`src/quill/llm.py`)
Update `LLMClient.chat` to accept Pydantic model classes in `response_format` and pass them directly to LiteLLM:
```python
def chat(
    self,
    system: str,
    user: str,
    temperature: float | None = None,
    max_tokens: int | None = None,
    response_format: dict | type[BaseModel] | None = None,
    ...
)
```

### 3. Stage Runner & Parsing Refactoring (`src/quill/stage_runner.py`)
*   In `run_feedback_stage` and `evaluate_output`, pass `FeedbackStageOutput` to `response_format`.
*   Parse LLM responses using `FeedbackStageOutput.model_validate_json(response)`.
*   Remove `parse_agent_response` and `_strip_json_block`.
*   Construct `AgentDecision` with `decision="advance"`, since automatic loop-back is deprecated under manual stage selection.

### 4. System Prompts & Templates Cleanups
*   **Prompt Builder**: Simplify default evaluation and feedback system prompts in `src/quill/prompt_builder.py` to remove legacy JSON formatting instructions.
*   **Agent Set Prompts**: Update all prompt flavors (`default`, `fiction`, `non-fiction`) to remove legacy JSON markdown code blocks, warnings, and decision guides.
    *   `agents/default/{review,validate,evaluate}.prompt.md`
    *   `agents/fiction/{review,validate,evaluate}.prompt.md`
    *   `agents/non-fiction/{review,validate,evaluate}.prompt.md`
